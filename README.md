### 关于 · about

> 天下大事，必作于细。—— 老子

我是 **Charles**。写代码，偶尔写点别的，住在 Aurora Sprawl —— 一座不存在的城市。

这句话记了很多年。它没标记抵达，只替我守住一个位置：在做成与做不成之间，在言说与沉默之间，暂且站住。

<details>
<summary><img src="https://cdn.jsdelivr.net/gh/Charles766/Charles766@main/assets/expand.svg" alt="更多"></summary>


最难熬的不是开头。开头有火，有还没被消耗的许诺，像泰戈尔那只夏天的飞鸟，飞到窗前，唱完就飞走。结尾也还好，哪怕潦草，至少有个形状。磨人的是中间：火不再跳，只剩均匀的暗热；方向还在，每一步却踩在重复里。荣格说，人后半程要面对阴影，那不是故障，是生命要求完整。中间那段的放弃，多半不是意志不够，是一直拿开头的火去量中间的热。尺子错了，便以为路断了。

后来我只挑一眼望得到头的事做。望不到头的，我知道自己走不完。

这像退守，其实是辨认。荣格的自性有边界，个体化从不完成。若"完成"本是幻象，望得到头就不是怯懦，而是诚实的几何：我承认自己有限，勇气只够覆盖一段有限的距离。与其把生命抵押给无限延展的中间，不如把小的做完。能收束的东西，哪怕小，沉默也有形状。泰戈尔说，沉默蕴蓄语声，如鸟巢拥围睡鸟。未完成不是空的；它是巢，里面睡着还没飞出去的东西。

维特根斯坦要求对不可言说者沉默。但他也说过，写出的与没写出的共同构成意义，而没写出的才重要。他不是逃进沉默，是在沉默边缘把能说的说完，让说不出的借边界显形。我做不到那种沉默。我的沉默会发酵，变成黏稠的、没有出口的在场。所以我把它写成代码。代码是我的"显示"：它不说不可言说之物，只搭一个结构，让那东西从缝隙里透进来。

住在 Aurora Sprawl，也就不只是自我安慰。一座不存在的城，正好安置不可言说者。我写下的每行能跑的代码，都是一个小小的、望得到头的完成——短，但不假。飞鸟不属于任何城，它路过，唱完，飞走。巢留下过。中间那段最没意思的路上，我学会不再要求自己成为永远在飞、永远不落地的鸟。

我做巢。鸟巢对天空的回答不是歌唱，也不是追问，是一种低矮的沉默：我在这里，有限，能收拢。够了。

<sub>Everything great is built from small things — or so I keep telling myself.</sub>
