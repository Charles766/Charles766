### 关于 · about

> 天下大事，必作于细。—— 老子

我是 **Charles**。写代码，偶尔写点别的，住在 Aurora Sprawl，一座不存在的城市。

我靠给虚空赋形过活。

屏幕之外是深夜，屏幕之内是一片空白，和创世之初的水面似乎没什么差别。某刻，我写下一行，它成立；再写一行，它开始和上一行发生关系。一个程序就这样从混沌里长出来：我命名，我划界，我告诉它什么该做，然后它跑起来，像一头终于学会呼吸的小兽。这是我能想象的、最接近造物的时刻。只是它常常跑不通，我得在凌晨，钻进自己砌的迷宫，找出当初是哪一步走错了。

<details>
<summary>一些随想</summary>



开头有火，是什么都还没被写坏；而结尾有形状，潦草也算。磨人的是中间：火不跳了，只剩下均匀的暗热，每一步都在重复。日光之下并无新事，我一度以为这是失败，后来疑心这是所有造物者的共同处境 —— 神在第七天歇了工，而我们这些学着祂样子造东西的人，要在第六天的泥泞里，待很久。

有一道裂缝，是有限者抬头望见无限时裂开的。也有一种无限是假的：一条永远到不了的直线，下一个版本，下一个目标，下一次“忙完就好了”，哪一站都不算数。真的无限是圆 —— 走完自己的路，在终点回到起点。一个能跑通的函数就是这样的圆，小，但是完整，不欠“下一个”什么。

荣格说，后半程要回头收拾自己的阴影。我学着认它：懒的，怯的，想逃的，那些被我亲手砍掉的部分。保罗也写过，我所愿意的善，我反不做。两千年前他在狱中写下这话时，大概也在某个深夜，惊讶于人的有限。完整比光明难看，也比光明结实；能力在软弱里才显得完全 —— 我从前当这是安慰，如今当它是事实。

我不再碰那些一眼望不到头的东西。试过之后，大概知道自己的手能伸多远了。能做完的，就把它做完。讲不出口的，我写进代码。代码虽不替我说话，它只是在那儿安静的跑着，而我想要的东西，有时候会自己从它身上透出来。

Aurora Sprawl 没有地图。可极光本就是太阳的火，穿过一亿五千万公里的冷，在最荒凉的夜空上自己显形。一座不存在的城，正好接住这种光。

鸟是天空的，路过，唱完，飞走。巢不飞，低矮，笨拙，风一吹就晃，只是在那儿：收拢过，有东西在里面睡过，然后飞走了。

年轻时我想当那只鸟。现在我做巢。

凡手底下能做完的，尽力做完，然后看着它，说一句：是好的。

<sub>And it was good.</sub>
