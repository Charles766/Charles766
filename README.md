### 关于 · about

> 天下大事，必作于细。—— 老子

我是 **Charles**。写代码，偶尔写点别的，住在 Aurora Sprawl —— 一座不存在的城市。

这句话我记了很多年。不是因为做成了什么大事，
而是反过来拿它给自己找台阶——做不了大的，就先做小的。

做东西最难熬的是中间那一段。开头有劲儿，结尾还远，中间只剩一堆没意思的活儿。
大部分东西就是在这儿放下的，我也是。

后来学乖了，只挑一眼能望到头的事做。望不到头的，我知道自己走不完。

维特根斯坦说，凡不可言说者，当沉默以对。
我做不到沉默，就把它们写成代码。

<sub>Everything great is built from small things — or so I keep telling myself.</sub>
